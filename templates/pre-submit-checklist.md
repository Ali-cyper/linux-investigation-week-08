# Pre-Submit Checklist

- [ ] Every field of the template is filled (no empty Medium or Weak, no cut-off sentence).
- [ ] Verdict, Confidence and the last sentence of the Summary agree with each other.
- [ ] Verdict uses only TP / FP / Undetermined; Confidence uses Low / Medium / High.
- [ ] Every claim in the Summary has a log line behind it; anything else is labelled an assumption.
- [ ] No term (spraying, brute force, C2, service, encryption) without direct evidence in this case.
- [ ] Nothing copied from a previous case: IPs, users, hosts and times all belong to this case.
- [ ] Operational impact is separated from security/data impact.
- [ ] Each evidence item says strong/medium/weak **on what**.
- [ ] Benign Explanation argues the normal case first, then says what it does not explain.
- [ ] "What Would Change My Mind" names concrete evidence, not "ask the user".
- [ ] Every SIEM Note says what it explains and what it does not; an unreviewed note counts as Missing Evidence.
- [ ] Recommended Action matches the verdict and the Missing Evidence.
- [ ] Time Spent is my own working time.
- [ ] Executive Summary is 3–5 complete English sentences with no pasted logs.
